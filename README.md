# CodeAlpha_Chatbot

## 📌 Description

This is a simple rule-based chatbot developed in Python as part of the CodeAlpha Internship. The chatbot interacts with users by responding to predefined inputs such as greetings, basic questions, and exit commands.

---

## 🚀 Features

* Responds to greetings (hello, hi, hey)
* Answers basic questions (e.g., "how are you")
* Provides help instructions
* Exit functionality (bye, exit, quit)
* Handles unknown inputs with fallback response

---

## 🛠️ Technologies Used

* Python

---

## ▶️ How to Run

1. Clone or download the repository
2. Open terminal in the project folder
3. Run the program:

   ```bash
   python chatbot.py
   ```

---

## 📂 Project Structure

* chatbot.py → Main chatbot logic

---

## 💡 How It Works

The chatbot uses simple conditional statements (if-elif-else) to match user input and return predefined responses.

---

## 📌 Example Interaction

You: hello
Chatbot: Hi!!

You: how are you
Chatbot: I'm fine, thanks!

You: bye
Chatbot: Goodbye!
